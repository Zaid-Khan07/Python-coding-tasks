# Python & Library Coding Tasks 🐍

This repository contains my daily Python tasks, coding challenges, logic-building exercises, and hands-on practice with various Python libraries.

---

### 📁 Repository Structure

- **`01_Python_Basics_and_Logic/`** - Conditional statements, loops, number patterns, and basic algorithms.
- **`02_Python_Data_Structures/`** - Lists, tuples, dictionaries, sets, and string manipulation tasks.
- **`03_Python_Functions_and_Modules/`** - Custom functions, recursion, decorators, and built-in modules practice.
- **`04_Python_OOPs_Concepts/`** - Classes, inheritance, polymorphism, encapsulation, and object-oriented projects.
- **`05_Python_Libraries/`** - Practical tasks and scripts using popular Python libraries:
  - **NumPy:** Multi-dimensional arrays, mathematical calculations, and vectorization.
  - **Pandas:** Data manipulation, DataFrames, CSV/Excel handling, and data cleaning.
  - **Matplotlib & Seaborn:** Data visualization, plotting graphs, and statistical charts.
  - **Requests & Web APIs:** REST API integration, HTTP requests, and JSON parsing.
